# Never Access tcrf.net

Never make any request to tcrf.net or www.tcrf.net (The Cutting Room Floor). That includes WebFetch, the web-fetch agent, `curl`, `wget`, browser automation, and any other tool or script that would contact the site. The site IP-bans users whose Claude agent tries to read it.

If a link or search result points there, use another source, or give the user the URL so they can open it themselves.
